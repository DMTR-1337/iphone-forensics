Prepare

    
Two sources are supported. Both read only; nothing is sent to iCloud or the internet.

    
A. Connect the iPhone

    
    
        
  1. Install Apple Devices (Microsoft Store) or iTunes for the USB driver and the Apple Mobile Device Service.
    2. 
        
  2. Connect by cable, unlock the iPhone, and tap Trust. The passcode is entered on the iPhone only, never here.
    3. 
        
  3. Close the Photos app while reading so the photo database does not change mid-copy.
    4. 
    

    
B. Use a local, unencrypted backup

    
    
        
  1. Preserve existing backups: archive them in Apple Devices / Finder, or copy the whole folder unchanged. A newer backup can overwrite an older one.
    2. 
        
  2. An encrypted backup cannot be inspected. Turning encryption off removes passwords, Wi-Fi and Health data from future backups.
    3. 
        
  3. With iCloud Photos on, the library is not in computer backups, so few photos may be found.
    4. 
        
  4. macOS protects the backup folder: grant Full Disk Access to the terminal running this tool.
    5.

    Search for remnants
    
    
    Searches the acquired data, not the phone's free space: unused space in Photos.sqlite for names of records that no longer exist, and caches for complete JPEG/PNG/HEIC/MOV/MP4 streams. Deleted files cannot be read back: iOS destroys each file's encryption key on deletion.
    
    
    
    
    
    
    Caveats
    
    
      
        
    • Thumbnails are low-resolution derivatives, not full-resolution originals.
      • 
        
    • A cached or thumbnail file without a matching original does not prove the original was deleted.
      • 
        
    • Only items that were in Recently Deleted when the data was read are listed. Permanently deleted photos cannot be recovered.
      • 
        
    • iCloud Photos, Optimize Storage and backup exclusions limit what exists locally.
